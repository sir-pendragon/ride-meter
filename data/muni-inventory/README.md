# 市町村の通行規制ページ台帳(関東1都6県)

調査途中の台帳です。`status` の意味:

- `found` / `found_empty` / `index_only`: 公式ドメインのページを実際に開いて確認した(一覧あり / 今は規制なし / 専用の一覧なし)
- `unverified`: 未調査・取得失敗・候補のみ(「無い」という意味ではありません)
- `not_found`: 検索したが見つからなかった。調べずに記録された所を含むため、「無い」という意味ではありません

市町村コードは使わず、アプリが `pref`(県名)+`name`(市町村名)で国土地理院の市町村表と照合します。
